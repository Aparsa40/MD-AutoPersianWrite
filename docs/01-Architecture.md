# مستند معماری پروژه (Milestone 1)

## مقدمه
پروژه `MD-AutoPersianWrite V.2.0.0` یک ویرایشگر مارک‌داون مدرن با رابط کاربری فارسی (RTL) است. در این میلستون، زیرساخت‌های پایه و اسکلت اصلی پروژه بنا شده است.

## اصول معماری (Architectural Principles)
1. **Modular UI:** تمامی بخش‌های رابط کاربری به کامپوننت‌های مستقل تقسیم شده‌اند (مانند `TopToolbar`، `EditorPane` و `PreviewPane`). این امر باعث می‌شود توسعه یک بخش به بخش‌های دیگر آسیب نرساند.
2. **CSS Variables & Theming:** برای سیستم مدیریت تم (Dark/Light) از متغیرهای CSS و کلاس‌های Tailwind استفاده شده است. این روش نیازی به جاوااسکریپت سنگین در زمان رندر ندارد و تغییر تم در کسری از ثانیه اعمال می‌شود (عملکرد High Performance).
3. **Strict Type Checking:** پروژه با تنظیمات دقیق TypeScript پیکربندی شده تا از باگ‌های زمان اجرا (Runtime Errors) تا حد ممکن جلوگیری شود.

## ساختار پوشه‌ها
- **`src/components`**: کامپوننت‌های UI کاملاً جدا شده (Presentational).
- **`src/styles`**: شامل `globals.css` برای تعریف متغیرهای پایه سیستم تم.

## گام‌های بعدی (Milestone 2)
در مرحله بعد، استور مدیریت وضعیت (Zustand) پیاده‌سازی شده و سیستم پردازش `React-Markdown` به بخش پیش‌نمایش متصل خواهد شد تا پیش‌نمایش زنده (Live Preview) فعال شود. همچنین قابلیت‌های پایه فایل (Export) افزوده می‌شود.
