# مستند پیاده‌سازی میلستون ۴ (KaTeX + Mermaid Support)

## تکنولوژی‌های استفاده شده و دلایل فنی
1. **KaTeX (`remark-math` + `rehype-katex`):**
   - به جای MathJax سنگین، از KaTeX استفاده شد. KaTeX به طور متوسط بیش از ۱۰ برابر سریع‌تر از MathJax فرمول‌های پیچیده LaTeX را رندر می‌کند که مانع افت فریم هنگام تایپ هم‌زمان (Live Preview) می‌شود.
   - فرمول‌های درون‌خطی با `$ ... $` و بلوکی با `$$ ... $$` پشتیبانی می‌شوند.

2. **Mermaid.js (`src/lib/mermaid/MermaidBlock.tsx`):**
   - ایجاد کامپوننت کاملاً ماژولار جهت شناسایی زبان `mermaid` در بلوک کدهای مارک‌داون.
   - هندل کردن خطاهای سینتکس دایاگرام به همراه هماهنگی تم دایاگرام‌ها (Light/Dark) بر اساس تم فعلی اپلیکیشن.
