# مستند سیستم تم‌ها و پیکربندی ظاهر (Milestone 3)

## خصوصیات سیستم تم
1. **تم‌های داخلی:**
   - **روشن (Light):** تم پیش‌فرض مناسب مطالعه و ویرایش طولانی.
   - **تاریک (Dark):** تم تاریک استاندارد جهت کاهش خستگی چشم.
   - **سپیا (Sepia):** تم گرم با تناژ قهوه‌ای مناسب برای مطالعه.
2. **ذخیره‌سازی وضعیت:** وضعیت تم در `localStorage` مرورگر حفظ شده و در بارگذاری‌های بعدی به طور خودکار اعمال می‌گردد.
3. **Syntax Highlighting:** کدهای قرار گرفته در بلاک‌های ` ```js ` با استفاده از کتابخانه `rehype-prism-plus` و استایل PrismJS هایلایت می‌شوند.
4. **تنظیمات تایپوگرافی:** قابلیت تغییر آنلاین سایز فونت، فونت‌فمیلی و رنگ متن انتخابی پیاده‌سازی گردید.
