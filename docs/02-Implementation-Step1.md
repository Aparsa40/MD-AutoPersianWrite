# مستند پیاده‌سازی میلستون ۲ (ویرایشگر پایه + پیش‌نمایش زنده + Export)

## کارهای انجام شده
**راه‌اندازی Zustand Store (****`src/store/useEditorStore.ts`****):**
   - نگهداری state اصلی متن، نام فایل و رفرنس textarea
   - افزودن تابع `insertTextAtCursor` جهت درج تگ‌های مارک‌داون بدون بهم ریختن موقعیت نشانگر.
2. **پیش‌نمایش زنده با `react-markdown` (`src/components/preview/PreviewPane.tsx`):**
   - اتصال متن ویرایشگر به پیش‌نمایش لحظه‌ای.
   - اضافه شدن پلاگین `remark-gfm` برای پشتیبانی از جدول، خط روی متن (Strikethrough) و چک‌لیست‌ها.
3. **منوی File و خروجی گرفتن (`src/lib/export/fileExport.ts`):**
   - ایجاد قابلیت خروجی گرفتن و دانلود مستقیم فایل `.md`.
   - امکان ایجاد سند جدید و ذخیره با نام سفارشی (Save As).

## وضعیت تست
- پروژه بدون خطای TypeScript بیلد می‌شود (`npm run build`).
- دانلود فایل `.md` در تمامی مرورگرها تست گردید و درست عمل می‌کند.
