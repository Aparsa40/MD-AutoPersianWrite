# MD-AutoPersianWrite V.2.0.0

ویرایشگر مدرن، ماژولار و راست‌چین (RTL) Markdown با پشتیبانی از فرمول‌های ریاضی KaTeX، دایاگرام‌های Mermaid، سینتکس هایلایت کدها و قابلیت اجرا به صورت PWA (وب‌اپلیکیشن).

## 🚀 ویژگی‌های اصلی
- **رابط کاربری فارسی (RTL):** طراحی شده بر پایه راست‌چین و فونت وزیرمتن.
- **پیش‌نمایش زنده (Live Preview):** همگام‌سازی لحظه‌ای ویرایشگر و پیش‌نمایش با سیستم Debouncing جهت پرفورمنس بالا.
- **فرمول‌نویسی ریاضی:** رندر سریع فرمول‌های LaTeX درون‌خطی `$ ... $` و بلوکی `$$ ... $$` با KaTeX.
- **رسم دایاگرام (Mermaid):** رندر زنده نمودارهای گانت، فلوچارت و کلاس با Mermaid.js و هماهنگ با تم برنامه.
- **سیستم تم پویا:** پشتیبانی از تم‌های روشن (Light)، تاریک (Dark) و سپیا (Sepia) با ذخیره‌سازی در LocalStorage.
- **تنظیمات تایپوگرافی:** تغییر سایز فونت، فونت‌فمیلی (وزیرمتن، ساحل، شبنم) و رنگ متن انتخابی.
- **معماری مبتنی بر پلاگین:** قابلیت توسعه نوار ابزار و افزونه‌های جدید (Plugin Ready).
- **قابلیت PWA:** امکان نصب به صورت وب‌اپلیکیشن روی دسکتاپ و موبایل.

## 🛠️ تکنولوژی‌ها
- **Core:** React + TypeScript + Vite
- **Styling:** TailwindCSS + CSS Variables
- **State Management:** Zustand
- **Markdown Engines:** React-Markdown + Remark-GFM + Remark-Math + Rehype-KaTeX + Rehype-Prism-Plus
- **Diagrams:** Mermaid.js

## 📦 نصب و اجرا
1. **نصب وابستگی‌ها:**
   ```bash
   npm install
```

## **اجرای سرور توسعه**:
```Bash

```

